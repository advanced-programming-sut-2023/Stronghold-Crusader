# Stronghold-Crusader

A recreation project inspired by **Stronghold: Crusader**, developed as part of an *Advanced Programming* course.

---

## 🏰 Overview

This project is a partial remake of the classic real-time strategy game **Stronghold: Crusader**, focusing on implementing core gameplay systems and multiplayer interaction using Java and Maven.

## ⚙️ How to Run

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/Stronghold-Crusader.git
   cd Stronghold-Crusader
   ```

2. **Run the Server**

   ```bash
   cd server/src/main/java/websocket
   java Server.java
   ```

3. **Run the Client**

   ```bash
   cd client/src/main/java/view
   java Main.java
   ```

Ensure you have **Java** and **Maven** installed and properly configured in your environment.

---

## 🧡 Tech Stack

* **Language:** Java
* **Build Tool:** Maven
* **Architecture:** Client–Server via WebSocket
